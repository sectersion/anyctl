# Kenwood TS-480 (SA/SAT/HX)

**Interface:** RS-232 CAT port (rear) or USB "PC" port → a COM port on Windows.
Protocol: plain **ASCII commands, each ending with `;`**; rig replies `OK;` / `ER;`
and/or a data line, also `;`-terminated. Baud: try 9600 8N1 (check rig Menu 041 /
PC settings). No auth, half-duplex.

> Note: "TS-" here is **Kenwood** — CAT = *Computer Aided Transceiver*, their
> published command system (operation manual chapter). This is a different
> protocol family from Yaesu CI-V despite both being called "CAT" colloquially.

## Core commands

| Send | Meaning |
|------|---------|
| `IF;` | the one-line status: VFO+freq+mode+filters+levels (see layout) |
| `ID;` | model ID (TS-480SAT etc.) — see ts480.c: byte selects 100W+AT / JP-50W / JP-20W |
| `FA11digits;` | set freq, Hz, zero-padded to 11 (e.g. `FA00014250000;` = 14.250 MHz) |
| `FB…;` | same for VFO-B |
| `MDn;` | mode: 1 LSB 2 USB 3 CW 4 FM 5 AM (+CWR/RTTY variants) — verify with `MD;` |
| `TX;` / `RX;` | PTT |
| `AI0;`/`AI1;` | auto-info stream off/on — **turn off or the port chats constantly** |
| `EXnn…;` | extended settings/meters |

## `IF;` reply layout (chars after `IF`)

`0`=VFO letter, `1–11`=freq Hz BCD-ish ASCII, `12–13`=mode, `14–16`=passband,
then cut/notch/noise/level fields. hamlib reads split at info[32], TX-VFO at
info[30]. Exact positions to be confirmed against the manual once on the wire.

## Gotchas (from hamlib source comments — the only OSS implementation)

- `RX;` while PTT already off → replies `?` or nothing; don't trust its ack.
- Split mode: setting the "back" VFO can transmit on the wrong frequency —
  hamlib does a null re-set of the other VFO to work around it. Re-set the
  ACTIVE VFO explicitly when in split.
- Some commands return only `;` (no `OK`) — the skip-verify list in kenwood.c.
- Terminator/echo behavior is a rig menu setting; if replies lack `;`, the
  read-until-`;` loop in `cat.py` will idle-timeout instead (still works, slower).

## Files

`cat.py` — serial client (status / raw cmd / set freq / PTT with confirm gate /
listen mode). hamlib `rigctld` is the heavyweight alternative (`rigctl -m 104`).
